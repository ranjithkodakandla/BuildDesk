# BuildDesk Vision

BuildDesk is a B2B SaaS platform for builders, construction companies,
surface contractors, and multifamily operators.

Problem:

Teams spend significant manual effort extracting information from drawings
to create deliverables for builders, installers, manufacturers, and logistics.

Goal:

Create a geometry-driven platform where structured inputs generate
multiple output packages automatically.

Primary customers:

- Builders
- Construction companies
- Surface contractors
- Multifamily operators

Initial pilot customer:

- Canyon Surfaces

Core capabilities:

- Shape library
- Dimension-driven generation
- Bulk dimension intake
- PDF package generation

Long-term strategy:

- White-label deployment
- Customer-specific domains
- Multi-tenant B2B SaaS
- Future StoneDesk integration

Relationship to StoneDesk:

StoneDesk serves manufacturers and logistics.

BuildDesk serves builders and construction workflows.

Future integration will occur through a shared geometry schema.
